# P5 - Semantic Bio Page

## Aim
Create a small introduction page using semantic HTML tags.

## Main points
header, main, section, ul and footer.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. Keep style.css in the same folder to load the page design.

## Result
A simple working example of semantic bio page.
