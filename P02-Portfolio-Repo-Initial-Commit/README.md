# P2: Portfolio repo with an initial commit

## Aim
Initialize Git in a portfolio folder and create the first commit.

## Commands
```bash
git init
git status
git add .
git commit -m "Initial commit"
git log --oneline
```

- `git init` initializes a local repository.
- `git status` shows the state of files.
- `git add .` stages the files.
- `git commit` saves a snapshot of staged changes.
- `git log --oneline` displays the commit history.

## Result
The portfolio folder becomes a Git repository and its first commit is saved.
