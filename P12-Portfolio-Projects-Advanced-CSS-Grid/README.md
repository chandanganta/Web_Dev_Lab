# P12 - Portfolio Projects Grid

## Aim
Arrange project cards in a grid and make selected cards span more than one row or column.

## Main points
repeat(), minmax(), grid-auto-rows, grid-column and grid-row.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser and resize it to see the grid adjust.

## Result
A simple working example of portfolio projects grid.
