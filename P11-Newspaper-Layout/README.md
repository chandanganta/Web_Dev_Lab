# P11 - Newspaper Layout using CSS Grid

## Aim
To create a newspaper-style webpage using HTML and CSS Grid.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Responsive media queries

## Files
- `index.html` - Structure and newspaper content
- `style.css` - Layout, styling and responsive design

## Features
- Three-column newspaper layout on desktop
- Featured article spanning two columns
- Sidebar for campus highlights
- Images and multiple news articles
- Responsive layout for tablet and mobile screens

## Result
A responsive newspaper-style webpage was created using CSS Grid.
