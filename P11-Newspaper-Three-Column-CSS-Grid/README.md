# P11 - Newspaper Layout Using CSS Grid

## Aim
Create a newspaper-style page with three columns using CSS Grid.

## Main points
grid-template-columns, gap and a responsive media query.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. On a narrow screen the columns move into one column.

## Result
A simple working example of newspaper layout using css grid.
