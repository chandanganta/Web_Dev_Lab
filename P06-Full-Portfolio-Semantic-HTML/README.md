# P6 - Portfolio Page Using Semantic HTML

## Aim
Make a portfolio page with sections for about, skills, projects and contact details.

## Main points
header, nav, main, section, article, aside and footer.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. The page structure is written in HTML and its design is in style.css.

## Result
A simple working example of portfolio page using semantic html.
