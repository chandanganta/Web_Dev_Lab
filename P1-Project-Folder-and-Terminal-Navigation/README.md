# P1: Project folder and terminal navigation

## Aim
Create a project folder and practise basic terminal navigation.

## Commands
```bash
mkdir my-portfolio
cd my-portfolio
pwd
touch index.html
ls
```

- `mkdir`: creates a folder.
- `cd`: moves into the folder.
- `pwd`: displays the current directory.
- `touch`: creates a file on macOS/Linux.
- `ls`: lists files and folders.

**Windows Command Prompt:** use `type nul > index.html` instead of `touch`, and `dir` instead of `ls`.

## Result
A project folder is created and its location and contents are checked.
