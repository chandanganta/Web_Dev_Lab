# P13 - Flexbox and Grid in One Layout

## Aim
Use Grid for the main page structure and Flexbox for navigation and project cards.

## Main points
CSS Grid for page columns and Flexbox for rows of items.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. The main content uses Grid while the navigation and cards use Flexbox.

## Result
A simple working example of flexbox and grid in one layout.
