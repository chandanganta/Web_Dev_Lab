# P7 - Design Tokens and Typography

## Aim
Use CSS variables to store common colours, spacing, font and border radius values.

## Main points
:root variables, reusable colours, spacing and typography.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. Check style.css to see the variables used for the page.

## Result
A simple working example of design tokens and typography.
