# P8 - Sticky Navbar and Card Overlay

## Aim
Keep the navigation bar at the top while scrolling and place an overlay inside a card.

## Main points
position: sticky, position: relative and position: absolute.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html and scroll the page to see the sticky navbar. The card overlay is styled in style.css.

## Result
A simple working example of sticky navbar and card overlay.
