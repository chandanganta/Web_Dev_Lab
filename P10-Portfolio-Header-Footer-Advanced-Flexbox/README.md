# P10 - Portfolio Header and Footer with Flexbox

## Aim
Use Flexbox to arrange the portfolio header, navigation, main content and footer.

## Main points
flex-direction, justify-content, align-items, flex-wrap and flex.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. Resize the window to check the responsive header and footer.

## Result
A simple working example of portfolio header and footer with flexbox.
