# P9 - Responsive Navbar and Card Grid

## Aim
Arrange the navigation links and project cards with Flexbox and adjust them for smaller screens.

## Main points
display: flex, flex-wrap, gap and a media query.

## Files
- `index.html` - page structure.
- `style.css` - page styling.

## How to run
Open index.html in a browser. Resize the browser window to see the layout change.

## Result
A simple working example of responsive navbar and card grid.
